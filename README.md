## 📋 Project Overview

A comprehensive C++ implementation of fundamental algorithms and problem-solving techniques, demonstrating sorting algorithms, searching algorithms, and greedy algorithms with detailed complexity analysis. This project is designed for educational purposes and internship submissions to showcase understanding of core computer science concepts.

### 🎯 Key Features

- **Sorting Algorithms** (3 implementations)
  - Bubble Sort with optimization
  - Merge Sort with divide-and-conquer
  - Quick Sort with median-of-three pivot

- **Searching Algorithms** (2 implementations)
  - Linear Search (sequential)
  - Binary Search (divide-and-conquer)

- **Greedy Algorithms** (2 implementations)
  - Activity Selection Problem
  - Coin Change Problem

- **Additional Features**
  - Step-by-step execution visualization
  - Performance comparison between algorithms
  - Random test data generation
  - Comprehensive complexity analysis
  - Time complexity tables
  - Memory usage analysis
